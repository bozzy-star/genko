# 元寇 — 8ビット風ブラウザゲーム

文永・弘安の役(元寇)をテーマにした、見下ろし型の縦スクロールアクションです。

**遊ぶ:** https://bozzy-star.github.io/genko/

HTML一枚で動きます。`index.html` をブラウザで開くだけで遊べます(サーバー不要)。

## 遊び方

- 移動: 矢印キー / WASD
- 攻撃: Z / Space(弓は矢を放つ、薙刀は撫で斬り)
- 持ち替え: X / Shift(第四面で薙刀を得てから)
- P 一時停止(操作説明) / M 音 / F 全画面
- タイトルで 1〜6 キーを押すと、その面から始められます
- スマホは画面下のボタンで操作できます

米俵をすべて集めると本陣に旗が立ち、旗に触れれば面クリア。倒した敵は「首級」として数えます。

## 面構成

1. 博多湾 — 大将なし
2. 石築地 — 大将マルコ・ポーロ(必殺「東方見聞録」)
3. 博多の町 — ボーナス面。四十秒で米俵を拾えるだけ拾う
4. 博多防衛戦 — 画面固定。上から来る敵を九十秒しのぐ。ここで薙刀を得る
5. 志賀島 夜討ち — 闇の中、見つからずに敵を射る
6. 鷹島沖 — 海上戦。小舟と漕ぎ手、風。大将フビライ・ハーン(必殺「集団戦法」)

## 技術

- 依存ライブラリなし。Canvas 2D と WebAudio のみ
- 効果音・BGM・掛け声(「えい」「おう」「一所懸命」「かみかぜじゃー」「ここじゃー」)はすべてコードで合成
- フォントは Google Fonts(DotGothic16 / Shippori Mincho B1)を読み込みます。オフラインでは代替フォントになります

## 参考

『蒙古襲来絵詞』『元史』日本伝、『高麗史』金方慶伝ほか。マルコ・ポーロとフビライ・ハーンは史実では元寇に来ていませんが、ゲームの大将として登場します。
